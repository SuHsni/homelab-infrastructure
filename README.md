# 00-professional-lab-setup

## Overview

This repository contains the initial setup of my professional IT lab environment.

The purpose of this project is to create a structured and documented lab that will be used throughout my IT Engineer Bootcamp. Future projects such as Windows Server, Active Directory, Networking, Linux Administration, PowerShell, and Security will all be built on top of this environment.

---

## Project Goals

- Build a professional virtual lab environment
- Follow enterprise naming conventions
- Document every step of the learning process
- Practice infrastructure documentation
- Prepare for real-world IT Support and System Administration roles
