# Host Machine

## Overview

This document describes the physical machine used to host the virtual lab environment.

---

## Hardware Specifications

| Component             | Specification                             |
| --------------------- | ----------------------------------------- |
| CPU                   | Intel Core i7-6500U (2 Cores / 4 Threads) |
| RAM                   | 8 GB                                      |
| Host Operating System | Windows 10                                |
| Hypervisor            | VMware Workstation                        |
| Storage               | SSD                                       |

---

## Purpose

The host machine provides the computing resources required to run the virtual infrastructure used throughout this homelab.

---

## Notes

Due to the limited RAM (8 GB), virtual machines will be started only when required during each lab.
